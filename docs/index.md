  ## Resumen Ejecutivo: Proyecto TechStore SV

TechStore SV es una aplicación móvil de comercio electrónico con fines académicos que simula el flujo completo de compras digitales, aplicando conceptos de desarrollo móvil, navegación y gestión de estado.

### Key Highlights del Proyecto

**Categoría y Propósito:**  
Tienda virtual comercial diseñada para enseñar y reforzar la programación de interfaces móviles y la persistencia de datos.

**Flujo de Navegación:**

$$\text{Login} \rightarrow \text{Registro} \rightarrow \text{Bienvenida (Home)} \rightarrow \text{Catálogo} \rightarrow \text{Carrito} \rightarrow \text{Perfil} \rightarrow \text{Logout}$$

**Tecnologías y Almacenamiento:**  
Arquitectura basada en componentes funcionales con React Hooks (`useState`, `useEffect`) y persistencia local mediante `AsyncStorage` para mantener sesiones y el carrito activos.

## Análisis Técnico y Conclusiones

- **UI/UX y Rendimiento:** Interfaz optimizada con listas en `FlatList`, diseño estilizado con gradientes y navegación fluida entre vistas.
- **Seguridad Básica:** Indicadores dinámicos de contraseña y validación de campos vacíos.
- **Conclusión:** La app cumple con los estándares requeridos para un e-commerce educativo, logrando una experiencia funcional, fluida y con datos persistentes.
