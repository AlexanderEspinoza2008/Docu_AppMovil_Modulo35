desarrollo móvil, navegación y gestión de estado.Key Highlights del ProyectoCategoría y Propósito: Tienda virtual comercial diseñada para enseñar y reforzar la programación de interfaces móviles y la persistencia de datos.Flujo de Navegación:$$\text{Login} \rightarrow \text{Registro} \rightarrow \text{Bienvenida (Home)} \rightarrow \text{Catálogo} \rightarrow \text{Carrito} \rightarrow \text{Perfil} \rightarrow \text{Logout}$$Tecnologías y Almacenamiento: Arquitectura basada en componentes funcionales con React Hooks (useState, useEffect) y persistencia local mediante AsyncStorage para mantener sesiones y el carrito activos.Estructura de Pantallas y FuncionalidadesPantallaVariables de Estado (useState)Funciones y Características ClaveLoginemail, password, de datos personales con alertas de validación.Análisis Técnico y ConclusionesUI/UX y Rendimiento: Interfaz optimizada con listas en FlatList, diseño estilizado con gradientes y navegación fluida entre experiencia funcional, fluida y con datos persistentes.
